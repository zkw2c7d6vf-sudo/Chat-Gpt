# Orbit 4.4 test build

Use Node.js 24 or later. In this extracted folder, run:

    npm ci
    npm run dev

Open http://127.0.0.1:5173 and keep Terminal open.

To keep your existing Google/Spotify connections, copy your old .env file and .orbit folder into this folder before starting. Finder shows hidden files with Command-Shift-period. Keep the same browser and address to retain browser-local tasks, notes, and media. This archive contains no credentials or personal account data.

Test calendar and inbox failure states, Google reconnection, Today, Planner, tasks, focus, weather settings, and Finances. Live provider access requires your own account configuration. Automated integration checks use simulated provider responses.
