⌖ Location & weather

Your browser requests location permission. Coordinates are sent to Open-Meteo for weather, kept only in this browser, and refreshed every 15 minutes. Windows may need Location services enabled.

Town names are resolved locally using GeoNames. City search overrides the nearest-town lookup. The clock uses the forecast location’s timezone.

⏻ Candle warmer · Kasa EP10

Enabling reads state only. Power changes happen only when you tap the warmer button. Use the same LAN and reserve the plug’s IP in your router. Newer firmware may require Kasa credentials as server environment variables; see README. Never expose this server to your network or the internet.
