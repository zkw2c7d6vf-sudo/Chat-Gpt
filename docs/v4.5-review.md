This build integrates the immersive Home work from PR #4 with Education Center, a real weekly Planner, File Studio, persistent Focus, and the existing dashboard. It is ready for local user testing. It has not been installed on Joe’s Mac, and authenticated provider behavior on that Mac remains a user acceptance check.

## How to run and roll back

Download into a separate folder. Keep the existing installation intact. Export a dashboard backup; privately copy `.env` and `.orbit` if reusing connections. Run `npm ci`, then `npm run dev`; open `http://127.0.0.1:5173` in the same browser. See README for details.

Use `http://127.0.0.1:5173/?classic-home=1` for the classic Home. Switching layouts does not replace provider configuration or records. Older releases remain available on their original branches. Do not run a folder-wide overwrite against unknown newer Mac work.

## Practical limits

- Google/Spotify/eBay/OpenAI require the user’s authorized setup; no account settings were changed. Playback still needs an eligible active Spotify device.
- Media is browser-local and codec-dependent; keep original files. Portable dashboard backups exclude media bytes.
- File Studio supports images and JSON/CSV, not PDF/Office/video transcoding. Inputs are temporary and never uploaded.
- Education is a local organizer, not an LMS/student-information-system integration. It does not send student records to AI.
- Background photos require Wikimedia access; local scenes work offline. Private image bytes are excluded from portable backups. Licenses remain with contributors.
- No public deployment, main-branch replacement or automatic installation on the Mac is claimed. Home-PC Jellyfin, bank connections, consumer delivery APIs and background autonomous development remain outside this release.
