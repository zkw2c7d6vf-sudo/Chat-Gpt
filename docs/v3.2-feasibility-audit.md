# Orbit v3.2 feasibility audit

Scope: functional refinement of the v3.1 branch. This review separates working features from optional account integrations and ideas that need outside provider approval.

| Area                                            | Result                                                                                  | v3.2 disposition                                                                                                                                                                                                          |
| ----------------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Calendar `.ics` import                          | Feasible and tested locally                                                             | Fixed loopback origin handling for `localhost` and `127.0.0.1`; imported files remain private server-side snapshots.                                                                                                      |
| ICS subscription                                | Feasible                                                                                | Kept. HTTPS/webcal feed validation, size limits, recurrence parsing, and five-minute cache are covered by service tests.                                                                                                  |
| Google calendar/mail/Drive                      | Feasible only with Google OAuth/API configuration                                       | Kept optional. It is not needed for ICS. It cannot be made live without the user's Google project and consent.                                                                                                            |
| Spotify                                         | Feasible with an existing Spotify app, a Premium playback device, and matching callback | Kept. Playback is tested against mocked provider responses; a real account/device is outside automated testing.                                                                                                           |
| Weather                                         | Feasible without an account                                                             | Kept. Open-Meteo search/current conditions are tested with validation and failure handling.                                                                                                                               |
| Voice and AI                                    | Partially feasible                                                                      | Browser dictation depends on the browser. Recorded transcription and open-ended AI require a separate OpenAI API key/billing. Kept optional and explicit.                                                                 |
| Media Center                                    | Feasible for local browser files                                                        | Kept. Browser codec support, storage quotas, 500 MiB import cap, and no DRM playback remain hard limits.                                                                                                                  |
| Daily Command Center                            | Feasible as local planning data                                                         | Combined commitments, goals, and habits into one daily workspace. It contains only entries Joe adds.                                                                                                                      |
| DoorDash tracking                               | Not feasible for arbitrary personal consumer orders                                     | Removed. DoorDash Drive documents partner-created deliveries, not a consumer-account lookup API.                                                                                                                          |
| Price comparison and personalized shopping feed | Not yet feasible as a reliable live product                                             | Added an honest prototype: local saved searches with direct retailer searches. Live prices, product matching, stock, affiliate feeds, and recommendations require authorized retailer or comparison-provider data access. |

## Validation

The regression suite verifies 52 server/storage/updater behaviors, including an ICS import from `http://localhost:5173` while rejecting a nonlocal hostile origin. Browser tests cover core overview/navigation, responsive layouts, saved local data, calendar/media/capture flows, and runtime errors. Provider calls are mocked, so this is not evidence that any private Spotify or Google account has been configured.
