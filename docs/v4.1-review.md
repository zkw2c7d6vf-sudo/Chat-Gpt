# Orbit v4.1 review

Orbit 4.1 is a refinement pass focused on the parts of the dashboard that should be useful every day.

## What changed

- Focus sessions now offer 5, 10, 25, 50, and custom-minute durations. The contained animation fills the focus card while a session runs. Sound is generated locally in the browser for steady rain, rain on a roof, rain on a window, a distant storm, soft snow, and hail.
- Media opens with a popular TVMaze row. The lower player area contains the YouTube no-cookie player and an integrated apps grid linking to official streaming sites with prominent service icons.
- Shopping Scout requests live eBay Browse results only when `EBAY_CLIENT_ID` and `EBAY_CLIENT_SECRET` are configured on the server. It displays listing images, condition, seller, price, shipping, and an external listing link. No credentials are sent to the browser.
- The duplicate Connections sidebar destination is gone. The bottom-left Joe avatar and profile/settings actions open one wide settings surface containing connections, assistant preferences, and backup controls.
- The overview status strip omits the disconnected-calendar label; the calendar page still explains how to add an ICS link or file.

## Boundaries

Retailers such as Amazon, Walmart, Target, Depop, and Vinted do not provide a dependable anonymous catalog API for this private dashboard. Their links remain available for searches, while eBay is an explicit opt-in provider. Streaming services keep playback and account state on their official sites. OMDb is optional for Rotten Tomatoes scores.

## Validation

Run `npm run build`, `npm test`, `npm run test:v41`, `npm run test:v31`, `npm run test:v3`, and `npm run test:e2e`.
