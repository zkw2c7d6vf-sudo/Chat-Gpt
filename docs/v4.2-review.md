# Orbit v4.2 review

Orbit 4.2 is a finishing pass for the dashboard's existing feature set.

- The focus rain animation now covers the whole timer card. Timer and sound controls stay above the translucent animation layer, and reduced-motion preferences still disable falling drops.
- Focus labels are shorter and the duration selector stays compact while supporting presets and custom minutes.
- Shopping Scout's introduction is shortened to describe its actions directly.
- The visible app version and package metadata now identify 4.2.

The established API tests cover OAuth state and service data, private calendar feed and ICS import, weather lookup, catalog search, shopping provider configuration, and assistant/transcription behavior. Browser checks cover the overview, weather, calendar, tasks, notes, focus, assistant, shopping, media playback, backups, and responsive layouts.
