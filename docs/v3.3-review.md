# Orbit v3.3 review

Scope: readability, calendar import recovery, useful local shopping comparison, and a durable design direction. V3.2 remains intact on `orbit-v3.2`.

## What changed

- Raised the most-used UI text sizes and made the clock larger. The clock now has a semantic morning, afternoon, or evening icon.
- Preserved the narrow loopback-only API-origin exception introduced in v3.2. Calendar setup now turns the prior raw origin rejection into a concrete recovery instruction: stop old Orbit processes, start this copy, and open `http://127.0.0.1:5173`.
- Parser-checked the private supplied `.ics` export without copying it into the repository, build assets, test fixtures, or documentation. It is valid, below the import limit, and produces upcoming events with the same server parser used by Orbit.
- Expanded Shopping Scout from outbound search links into a private comparison board. A saved search becomes a feed item; listings can have retailer, price, shipping, optional link, and note. The lowest saved delivered total is marked. Existing v3.2 saved searches migrate forward.
- Added [design-philosophy.md](design-philosophy.md), covering hierarchy, calm visual language, privacy, honest capability boundaries, and how future ideas should grow.

## Limits that remain intentional

Calendar data cannot be installed into a downloaded Orbit copy remotely; import the private file from the calendar connection panel after starting the matching local server. Shopping Scout compares entries you save. It does not scrape Amazon, Walmart, Target, Depop, Vinted, or any other retailer, and it does not present an unverified live price as fact.

## Validation

`npm run build`, 52 server/storage/updater tests, 17 media/dashboard browser tests, and 8 visual/browser checks pass. The calendar parser check used the supplied private export only in the isolated workspace and did not print or retain event details.
