# Orbit v4.0 review

V4 adds two media capabilities and a deeper shopping workflow while preserving the private, navy workspace established in v3.1–v3.3.

## New capabilities

- TVMaze discovery: searches real show records, displays their catalog images, opens cast details, and links to IMDb. TVMaze is a free public catalog; its rating is shown as a TVMaze rating and is not mislabeled as Rotten Tomatoes.
- Optional Rotten Tomatoes ratings: OMDb can return a Rotten Tomatoes rating when `OMDB_API_KEY` is configured privately. The disconnected state is explicit.
- YouTube player: accepts standard YouTube and youtu.be URLs, uses `youtube-nocookie.com`, supports a local saved-video list, and respects YouTube’s embed permissions.
- Free-service shelf: Tubi and Pluto searches plus Sling Freestream open their official sites. Their catalogs are not embedded because availability and framing are provider-controlled.
- Shopping images: saved listings can carry HTTPS listing and image URLs. Price plus shipping is compared locally, and the lowest saved total is marked.
- Local recommendations: saved search terms produce a small related-search shelf (for example, a saved jacket search can suggest outerwear). It is a transparent local heuristic, not a claim that Orbit has watched or profiled Joe.
- Rain focus mode: a bounded rain animation and Web Audio noise generator run only when Joe enables them during a focus session.

## Capability boundaries

Retailers do not provide a dependable free cross-store personal shopping API that Orbit can use anonymously. Orbit therefore does not scrape Amazon, Walmart, Target, Depop, Vinted, or protected image URLs. A future provider-backed feed can be added through an approved catalog or affiliate API with documented freshness and coverage.

Tubi, Pluto TV, Sling Free, and similar services may block iframe playback, change their catalogs, or require their own accounts. Orbit links to them and embeds YouTube only where the provider exposes an embed route.

## Validation

The build and existing service/storage/media browser suites remain required. V4 adds API tests for catalog normalization, cast results, and optional-rating behavior, plus browser checks for YouTube URL validation, saved listings with images, and rain focus controls.
