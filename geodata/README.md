# Local town names

GeoNames cities1000 snapshot, downloaded November 17, 2026 from https://download.geonames.org/export/dump/cities1000.zip .

Attribution: GeoNames, https://www.geonames.org/ . Licensed under Creative Commons Attribution 4.0: https://creativecommons.org/licenses/by/4.0/ . Source format and license: https://download.geonames.org/export/dump/readme.txt .

`towns.json.gz` is a reduced extract containing populated-place names, latitude and longitude. Historical, abandoned and subdivision entries are excluded. Coordinates are matched to the nearest populated place within 50 km. This is not a municipal boundary database; users can select an exact city in the existing city search. Lookup runs locally; user coordinates are not sent to GeoNames or another geocoding service.
